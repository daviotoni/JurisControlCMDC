        Integração Jurisprudências.ai

        Cole o token de API (jur_...) da conta do Jurisprudências.ai. Ele fica guardado no banco (visível só para administradores) e alimenta a busca integrada do painel Jurisprudência.

        Assistente de IA (Gemini)

        Cole a chave da API do Gemini (AQ.... ou AIza...). Crie uma gratuita em aistudio.google.com/apikey, escolhendo um projeto sem cobrança (para não gerar custo). Ela fica guardada no banco (visível só para administradores) e habilita o botão Assistente IA no editor de parecer.

        Modo gratuito: o Google pode usar o conteúdo enviado para treinar seus modelos. Não envie dados sigilosos ou pessoais de processos (nomes, CPF, endereços). Use para temas, redação e revisão de texto.
